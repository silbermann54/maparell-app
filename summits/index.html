Maparell summit database

The summit list included in Maparell is extracted from OpenStreetMap: every node tagged natural=peak or natural=volcano that has a name, with its OpenStreetMap id, position, name and height (ele, in metres, when it can be read).

Data © OpenStreetMap contributors. This database is made available under the Open Database License (ODbL) 1.0; see also openstreetmap.org/copyright.

Peaks.bin — the database exactly as included in the app.

build-peaks.py — the script that creates it from an OpenStreetMap planet file; its header describes the file format.
